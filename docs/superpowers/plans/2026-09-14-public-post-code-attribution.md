# Public Post Code Attribution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every new Threads post from every executor a short `Day N` marker backed by one shared allocator, then use that marker plus publication-time validation for exact Activity follow attribution.

**Architecture:** Postgres atomically reserves a per-account internal sequence. A shared Python allocator deterministically permutes that sequence into a 1–4 digit public code, persists the reservation before publishing, and finalizes it with the Threads media ID/timestamp afterward. Activity matching checks the public code first and writes current/best attribution separately from append-only raw Activity observations; legacy text matching remains the fallback.

**Tech Stack:** Python 3.11+, stdlib `hashlib`/`hmac`/`math`, httpx, PostgreSQL/Supabase REST + RPC, pytest.

**Spec:** `docs/superpowers/specs/2026-09-14-public-post-code-attribution-design.md`

## Global Constraints

- Public marker is exactly `Day <code>` followed by one blank line and the original body.
- Public codes are decimal integers 1–9999 with no leading zeroes.
- Public code digit width must match the internal sequence bucket: 1–9, 10–99, 100–999, 1000–9999.
- Codes are unique per `account_key`; code reuse is forbidden in v1.
- Sequence 10,000 must fail closed before publication.
- `THREADS_POST_CODE_SECRET` stays outside Git and logs.
- `threads_activity_events` remains append-only.
- `exact` is stronger than `high`; legacy high/medium/low/unknown matching remains available.
- Existing Insights collection must remain isolated and passing.

- [ ] **Step 3: Implement keyed affine permutation**

Use bucket helper:

```python
def _bucket(value: int) -> tuple[int, int, int]:
    if 1 <= value <= 9:
        return 1, 9, 1
    if 10 <= value <= 99:
        return 10, 90, 2
    if 100 <= value <= 999:
        return 100, 900, 3
    if 1000 <= value <= 9999:
        return 1000, 9000, 4
    raise PostCodeCapacityError(value)
```

Derive deterministic bytes with:

```python
material = f"post-code-v{scheme_version}|{account_key}|{width}".encode()
digest = hmac.new(secret.encode(), material, hashlib.sha256).digest()
```

Derive `b = int.from_bytes(digest[:8], "big") % size`. Derive candidate `a` from the next 8 bytes, map to `1..size-1`, then increment/wrap until `math.gcd(a, size) == 1`. Encoding uses `(a*x+b) % size`; decoding uses `pow(a, -1, size)`.

Render using exact regex semantics equivalent to:

```python
PUBLIC_CODE_RE = re.compile(r"^Day ([1-9]\d{0,3})(?:\r?\n|$)")
```

If text already begins with the same marker, return unchanged. If it begins with a different `Day N` marker, raise rather than silently replacing it.
